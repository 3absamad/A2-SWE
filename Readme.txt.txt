Project: Smart Budget App
Course: CS251 — Introduction to Software Engineering

Files included:
- app/Main.java — entry point, main menu
- view/ — all UI screens (RegistrationUI, LoginUI, etc.)
- controle/ — all controllers (AuthController, etc.)
- model/ — data classes (UserAccount, Transaction, etc.)
- repo/DatabaseManager.java — file-based data persistence

Tools used:
- Language: Java
- Storage: Text files (.txt)
- Documentation: JavaDoc
- IDE: VSC

How to run:
1. Open project in your Java IDE
2. Run Main.java
3. Data files (users.txt, transactions.txt, etc.)
   are created automatically in the project root
